# Classic Bags Thanjavur - E-Commerce Customer Store

Official e-commerce customer storefront for **Classic Bags Thanjavur** (Eco-Friendly Paper Bags Manufacturer).

📍 **Location:** Plot No. 38, 6th Street, Medical College Road, LIC Colony, Thanjavur - 613007  
📞 **Phone:** +91 98432 75685  

## Store Features
- **Responsive Flipkart-Style Gallery**: High-res multi-angle photography with thumbnail selector & smooth zoom (4:5 mobile & 16:9 desktop aspect ratios).
- **Interactive Bag Customizer**: Real-time GSM paper thickness selection, handle types (twisted loop, flat tape, d-cut), dimensions, and live custom logo upload mockup.
- **Zero-Fee UPI & Dynamic Matching**: Seamless UPI Intent & QR payment with dynamic paise pairing for 1:1 automated order matching.
- **Instant WhatsApp Inquiries**: Direct connection to the manufacturing desk for custom bulk quotes.

## Tech Stack
- React 18 + Vite
- Tailwind CSS
- Lucide React Icons
- CryptoJS

## Getting Started
```bash
# Install dependencies
npm install

# Start local customer storefront (Port 3001)
npm run dev

# Build production bundle
npm run build
```
